Fixed = cam locked. Adjustable = sits on shelf pins. Loose = sized only.

LAYOUT RULE

Cams at each end of a joint, extra cams when the span exceeds the max spacing, one dowel beside each cam.

HARDWARE (mm)

All hardware fields are inches; the mm equivalent shows under each box. Pins and dowels run at MID-THICKNESS of the joining panel. The cam nut is bored deeper than its height — bore depth = nut height + (t/2 − nut slot distance) — so its slot lines up with the mid-thickness pin. The face hole takes the 3/8" pin insert.

EDGE MATERIAL

Any dimensional box accepts mm or fractions and converts to inches: type 32mm, 3/4 or 1-1/2 and tab out. Sizes you enter are FINISHED sizes. Cut size = finished + premill − band on each banded edge, so the case comes out exactly the size entered. The cut list shows both.

OUTPUT

CNC

CNC #1 EDGE FILES writes one .nc file per panel that has edge drilling, in the CNC #1 edge-drilling app's own format — open each in that app with LOAD FILE, review, then generate. Panel width/length/thickness, qty, cam and dowel positions per edge, and the hole depths all come across; machine settings (tool, origin, feeds, park) use the CNC #1 defaults. Glide holes are left out — different bit.

DXF R12, inches. Each drawing shows the face that lies UP on the CNC when drilling — the VIEW label and the FACE UP column on the cut sheet say which face that is. Layer names carry tool and depth (CAM_D15_Z12_7, EDGE_PIN_D8_Z35_9 — decimals written with underscores, AutoCAD forbids periods in layer names). Holes drilled from the opposite face are suffixed _UNDERSIDE / _FARFACE and marked on the drawing. Panel outlines are written as single closed polylines, ready to select as one profile in CAM. Every hole also gets a POINT at its center on a matching _PT layer for picking drill positions in Mastercam. NESTED SHEETS lays every panel (qty included, CUT sizes, rotation allowed) onto the chosen stock, one sheet outline per sheet, holes positioned for drilling on the raw blank before edgebanding.
